This Repository contains the data used in the Data-Driven Inference of Fluid Properties Using Structural Response Signature paper.
The repository also contains the code of the ML models used to train the dataset.
Paper Link: https://iopscience.iop.org/article/10.1088/1742-6596/3151/1/012015
